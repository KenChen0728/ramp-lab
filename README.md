# 胡桃鉗下坡實驗室

2026 國家圖書館冬季講堂「胡桃鉗大戰老鼠王：逐步下坡玩具科學體驗」（2026-11-07）用的網頁，有三個分頁：下坡模擬器、三個秘密、在家玩。

- 網址：https://kenchen0728.github.io/ramp-lab/
- 目前版本：**2026.11.05-1**（網頁最下面看得到；點版本號會打開裝置資訊，回報問題時可以截圖）
- 製作：國立屏東科技大學　陳則翰、許衷源、鄭博元 老師

## 檔案

## 不能改的地方

- 模擬器的判斷門檻依照 10/30 在長坡道（42 公分）實測的結果設定：砂紙 13°、17°、21°，木板 13°、17°。改了模擬結果就會和實測不一樣。
- 士兵刻度 1～7（可到 .5），和木馬身上畫的刻度一樣。
- 三個分頁：下坡模擬器、三個秘密、在家玩。

## 2026.11.05-1 健檢更新

用手機（360～430 寬，直放和橫放）、平板（iPad mini～12.9 吋，直放和橫放）、電腦（1280～1920 寬），淺色和深色都跑過；也測了重新整理、沒網路、連點、亂填數字、減少動態效果。

**修正**

1. 加上版本號，點開會顯示裝置資訊。
2. 手機橫放（沒開全螢幕）時動畫下面被切掉，往下捲就看不到動畫：現在標題列變窄，動畫整個放得進畫面，而且固定在左邊，右邊的控制項可以捲。
3. 手機橫放開全螢幕時，上方會露出 8px 底下的網頁：已修正。
4. 13°、17°、21° 按鈕看不出現在選哪個：選中的會變深藍色。
5. 按返回鍵或改網址後面的 `#secrets` 不會換分頁：現在會跟著換。
6. 三支影片原本一打開網頁就全部下載（約 1.7 MB）：現在打開「三個秘密」才下載，先顯示預覽畫面，網路慢或沒網路時不會是空白。
7. GitHub 上的影片換成手機可以邊下載邊播的版本。
8. 「在家玩」換算：長度空白或填了太大的數字時，表格不再留著舊數字，「用這個角度去模擬器試試」會先變灰。
9. 「重心」「支點」的字加了白邊，不會和木馬、坡道混在一起；木馬走到坡底時「支點」改寫在旁邊，不會壓到下面的「板長、坡度」。
10. 深色模式的坡道太暗：改成比較亮的木頭色。
11. 按鈕和勾選框加大到手指好按（至少 44px 高）。
12. 文字：上方小標改成「國圖冬季講堂・胡桃鉗大戰老鼠王」；加上一句「調坡度、移士兵、換地面，看木馬能不能一步一步走下坡。」；動畫說明改成「動畫依照老師在長坡道實測的結果設定」。
13. 外觀改成簡報的胡桃鉗配色：深藍制服色標題列加飄雪、紅金飾帶、米色紙底；士兵位置滑桿下面加上和木馬身上一樣的 1～7 刻度尺；模擬畫面加上雪花和小松樹。
14. 加到主畫面：新圖示、名稱「下坡實驗室」；從主畫面打開時，手機狀態列下面保持深藍色，劉海和底部橫條不會擋到全螢幕的按鈕。

**還沒用真的裝置確認**

- iPhone、iPad 的 Safari：自動測試只能用 Chrome 核心，影片播放、全螢幕轉向、主畫面 App 要實機看。
- 新的主畫面圖示：要先把舊的捷徑刪掉，再用 Safari「分享 → 加入主畫面」重新加一次才會換。
- 教室投影機上的實際大小。
- LINE 分享預覽（預覽圖沒有改，應該跟原本一樣）。
