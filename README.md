# 胡桃鉗下坡實驗室

2026 國家圖書館冬季講堂「胡桃鉗大戰老鼠王：逐步下坡玩具科學體驗」（2026-11-07）用的網頁。打開先看到首頁，按「開始玩」進到三個分頁：下坡模擬器、三個秘密、在家玩。開過一次後，沒有網路也能用。

- 網址：https://kenchen0728.github.io/ramp-lab/
- 目前版本：**2026.11.05-2**（網頁最下面看得到；點版本號會打開裝置資訊，回報問題時可以截圖）
- 老師投影直接用網址進分頁，不經過首頁：`#sim`（模擬器）、`#secrets`（三個秘密）、`#home`（在家玩）
- 製作：國立屏東科技大學　陳則翰、許衷源、鄭博元 老師

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 整個網頁：版面、文字、模擬器、使用說明都在這一個檔案 |
| `sw.js` | 離線功能：開過一次後把檔案存到裝置裡 |
| `help/` | 使用說明的圖片（真實畫面截圖；加到主畫面的 5 張是示意圖） |
| `tools/` | 重新產生說明圖片的工具，網頁本身用不到 |
| `media/secret1.mp4`～`secret3.mp4` | 三個秘密的影片（手機可以邊下載邊播的版本） |
| `media/secret1.jpg`～`secret3.jpg` | 影片載入前先顯示的畫面 |
| `media/start.jpg`、`media/home-art.png` | 首頁和「在家玩」的圖片 |
| `icons/` | 加到主畫面的圖示：月亮前的木馬和胡桃鉗士兵走下坡 |
| `manifest.webmanifest` | 加到主畫面時的名稱（下坡實驗室）、顏色和圖示 |
| `IMG_5353.png` | LINE／臉書分享時的預覽圖（`index.html` 第 8 行指到它，不要改名） |

## 不能改的地方

- 模擬器的判斷門檻依照 10/30 在長坡道（42 公分）實測的結果設定：砂紙 13°、17°、21°，木板 13°、17°。改了模擬結果就會和實測不一樣。
- 士兵刻度 1～7（可到 .5），和木馬身上畫的刻度一樣。
- 三個分頁：下坡模擬器、三個秘密、在家玩。
- 這個網域還放了其他程式，快取和 localStorage 是共用的：`sw.js` 只能動 `ramp-lab-` 開頭的快取；以後要用 localStorage，key 也要加 `ramp-lab-` 開頭。

## 改版時要做的事

1. `index.html` 的 `VERSION` 和頁尾版本號、`sw.js` 的 `VERSION`、這份說明的版本號，四個地方一起改。`sw.js` 的版本一改，舊的網頁快取就會自動清掉。
2. 影片內容換掉時，才把 `sw.js` 的 `MEDIA` 後面的數字加 1；沒換就不要動，不然每台裝置都要重新下載影片。
3. 新增或改名 `help/` 的圖片時，`sw.js` 的 `HELP` 清單也要改。
4. 介面改了，就用 `tools/help-shots.js` 重新截說明圖片。

## 2026.11.05-2 更新

**週六活動要用的修正**

1. 斷線後按秘密分頁，影片不會再變空白。之前每次都重新下載，現在已下載的影片會留著。
2. 字型伺服器卡住時不會再白畫面最多 30 秒，畫面立刻出現，字型載到了才換上。
3. iPhone 省電模式擋掉自動播放時，影片上會出現「點這裡播放」；影片載不到時有提示，也能再試一次，網路回來會自動恢復。

**新功能**

4. 離線：開過一次後，沒有網路也能用三頁、影片和使用說明。網路卡住超過 3 秒、斷線或網站回錯誤頁，就改用存好的版本。首頁會顯示「已經存好了」。
5. 開始畫面：活動名稱、「開始玩」、「看使用說明」。每個分頁上方有回首頁和問號。
6. 使用說明：四個主題（模擬器、三個秘密、在家玩、加到手機主畫面），左右切換，有目錄、上一張下一張，問號會直接打開該頁的說明。
7. iPhone 上下邊：拿掉 black-translucent，改用和排球記錄表相同、已在實機確認的做法，飾邊用胡桃鉗紅金色。

**改善**

8. 模擬結果放回來了：走完才揭曉，手機上跟著動畫一起釘住，寬螢幕疊在天空的位置。
9. 手機上氣泡字從 9～11px 加大到 17～19px，也不會蓋到時間和結果。
10. 按鈕加大：分頁、快捷鈕 52、選項 56、主要按鈕 64，滑桿圓鈕 40；小字加大。
11. 揭曉後自動捲到答案；手機影片下面提示可以看大畫面；LINE、Facebook 裡打開時提示改用瀏覽器。
12. 開「減少動態」的手機還是看得到走路，只走一次；板子填太短時木馬不會跑出畫面；按上一頁回來時控制項和動畫一致；介面符號圖示改成文字；加上防止連按時放大頁面的設定。

**模擬器的判斷沒有改**：1,612 種設定跑過，結果分布和上一版完全相同。只改了一句說明文字：「沒有重力往下拉」改成「重力沒辦法把它往坡下拉」，因為平地也有重力。

**還沒用真的裝置確認**

- iPhone、iPad 的 Safari：省電模式、影片斷線播放、主畫面 App 的上下邊和全螢幕，自動測試都只能用 Chrome 核心模擬。
- 主畫面 App 的影片和說明：要先刪掉舊捷徑再重新加一次，並先開網頁等它存好。
- LINE、Facebook 內建瀏覽器、學校舊平板、場地 Wi-Fi 和投影機。

## 2026.11.05-1 健檢更新

用手機（360～430 寬，直放和橫放）、平板（iPad mini～12.9 吋，直放和橫放）、電腦（1280～1920 寬），淺色和深色都跑過；也測了重新整理、沒網路、連點、亂填數字、減少動態效果。

**修正**

1. 加上版本號，點開會顯示裝置資訊。
2. 手機橫放（沒開全螢幕）時動畫下面被切掉，往下捲就看不到動畫：現在標題列變窄，動畫整個放得進畫面，而且固定在左邊，右邊的控制項可以捲。
3. 手機橫放開全螢幕時，上方會露出 8px 底下的網頁：已修正。
4. 13°、17°、21° 按鈕看不出現在選哪個：選中的會變深藍色。
5. 按返回鍵或改網址後面的 `#secrets` 不會換分頁：現在會跟著換。
6. 三支影片原本一打開網頁就全部下載（約 1.7 MB）：現在打開「三個秘密」才下載，先顯示預覽畫面，網路慢或沒網路時不會是空白。
7. GitHub 上的影片換成手機可以邊下載邊播的版本。
8. 「在家玩」換算：長度空白或填了太大的數字時，表格不再留著舊數字，「用這個角度去模擬器試試」會先變灰。
9. 「重心」「支點」的字加了白邊，不會和木馬、坡道混在一起；木馬走到坡底時「支點」改寫在旁邊，不會壓到下面的「板長、坡度」。
10. 深色模式的坡道太暗：改成比較亮的木頭色。
11. 按鈕和勾選框加大到手指好按（至少 44px 高）。
12. 文字：上方小標改成「國圖冬季講堂・胡桃鉗大戰老鼠王」；加上一句「調坡度、移士兵、換地面，看木馬能不能一步一步走下坡。」；動畫說明改成「動畫依照老師在長坡道實測的結果設定」。
13. 外觀改成簡報的胡桃鉗配色：深藍制服色標題列加飄雪、紅金飾帶、米色紙底；士兵位置滑桿下面加上和木馬身上一樣的 1～7 刻度尺；模擬畫面加上雪花和小松樹。
14. 加到主畫面：新圖示、名稱「下坡實驗室」；從主畫面打開時，手機狀態列下面保持深藍色，劉海和底部橫條不會擋到全螢幕的按鈕。

**還沒用真的裝置確認**

- iPhone、iPad 的 Safari：自動測試只能用 Chrome 核心，影片播放、全螢幕轉向、主畫面 App 要實機看。
- 新的主畫面圖示：要先把舊的捷徑刪掉，再用 Safari「分享 → 加入主畫面」重新加一次才會換。
